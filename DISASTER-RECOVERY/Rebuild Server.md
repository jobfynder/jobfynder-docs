# Rebuild Server

Generic template — as of 2026-09-07, every server on the platform falls under one of three provider-specific runbooks, each with real, verified detail: `Recover DigitalOcean.md` (`jobfynder-comm1`, `jobfynder-intel-01`), `Rebuild Hostinger Server.md` (`jobfynder-core`, `jobfynder-n8n`), or Elest.io's own per-service dashboard tooling (Update config / Restart / Change version — see `Infrastructure/SERVER-INVENTORY.md` for the 8 services). Use this file only if a server exists outside those three providers; otherwise go directly to the provider-specific doc.
