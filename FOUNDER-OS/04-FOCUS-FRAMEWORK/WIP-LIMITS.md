# WIP Limits

Maximum 3 active tasks at once (see `DAILY-CHECKLIST.md`). A task counts as "active" once work has actually started on it, not once it's been thought about.

**Why 3:** fewer means idle capacity when something blocks; more means the context-switching cost eats the gains of doing several things "in parallel." If a 4th task feels urgent, something currently active needs to finish, get parked in `PARKING-LOT.md`, or get explicitly dropped first — not silently deprioritized while still nominally "in progress."
