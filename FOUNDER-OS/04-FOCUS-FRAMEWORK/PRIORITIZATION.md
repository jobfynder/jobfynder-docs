# Prioritization

When evaluating what to work on next, score against these dimensions — the same framework already used for Jobfynder business decisions generally:

1. User value
2. Adoption potential
3. Revenue impact
4. Engineering complexity
5. Infrastructure cost
6. Maintenance effort
7. Strategic differentiation
8. Long-term scalability

Recommend the option with the strongest overall balance, not the most technically impressive one.
