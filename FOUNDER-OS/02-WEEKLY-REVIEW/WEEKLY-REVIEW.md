# Weekly Review

Run this once a week, ideally the same day each week.

## What actually happened

- Check `engineering-memory/daily/` entries for the week — what shipped, what broke, what got fixed. This is generated automatically; don't re-derive it from memory.
- Check which ADRs were filed this week under `FOUNDATION/ENGINEERING MEMORY/adrs/` — any real decision should have left a trace here.
- Check the feedback board (feedback.jobfynder.com) for new items across roles and modules.

## Focus check

- Did daily outcomes stay within the WIP limit all week, or did scope creep in?
- Review the Parking Lot (`../04-FOCUS-FRAMEWORK/PARKING-LOT.md`) — anything there earned promotion to an actual task this week?

## Decision quality

- Any decision made this week that should have been an ADR but wasn't? File it retroactively.
- Any repo, doc, or tool from this week that's now stale and should be archived rather than left to confuse things later?
