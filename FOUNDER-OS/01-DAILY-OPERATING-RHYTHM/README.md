# Daily Operating Rhythm

The founder's day-to-day execution system. It exists to reduce decision fatigue and make sure each day produces one completed, meaningful outcome rather than scattered activity.

- **`DAILY-CHECKLIST.md`** — the actual checklist, used every working day.
- **`DAILY-RHYTHM.md`** — how the day is structured around that checklist.
- **`DAILY-TEMPLATE.md`** — a fill-in copy of the daily reflection questions.
