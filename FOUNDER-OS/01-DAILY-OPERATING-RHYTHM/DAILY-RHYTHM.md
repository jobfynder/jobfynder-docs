# Daily Rhythm

`DAILY-CHECKLIST.md` is the mechanism; this describes when it gets used.

## Structure

**Start of day** — run the Daily Startup Checklist section: confirm today's single outcome, confirm it's within the WIP limit (max 3 active tasks — see `../04-FOCUS-FRAMEWORK/WIP-LIMITS.md`), route any new idea that isn't today's outcome to the Parking Lot instead of starting it.

**During the day** — track which artifact stage you're in (Discover → Design → Review → Specification Frozen → Implementation → Verification → Commit → Retrospective). When work spans multiple AI tools (Cursor, Codex, Claude Code), this stage is what makes handoff between them coherent — verification done in one tool doesn't need repeating in another.

**End of day** — run the End-of-Day Review and Daily Reflection sections of the checklist. Anything that should become a reusable system goes to `../05-LEARNING-SYSTEM/KNOWLEDGE-CAPTURE.md`. Anything that should be automated is a candidate skill, or a Hermes automation once Phase 1 agents are running.

## Guiding principle

Same as the checklist: a successful day is measured by completed meaningful artifacts, not activity volume.
