# Knowledge Capture

Every correction worth remembering goes to one of these places — not into this file directly:

- **A real architecture or technical decision** → `FOUNDATION/ENGINEERING MEMORY/adrs/` (one file per decision, following `adr.schema.json`).
- **A day-to-day engineering event** → captured automatically in `engineering-memory/daily/` via the GitHub webhook automation — no manual action needed.
- **A correction to how an AI tool should behave in a repo** → that repo's `AGENTS.md`.
- **An idea that isn't ready yet** → `../04-FOCUS-FRAMEWORK/PARKING-LOT.md`.

This file exists to say where things go, not to hold them itself — scattering corrections across purpose-built homes is what makes them findable later instead of buried in one giant log.
