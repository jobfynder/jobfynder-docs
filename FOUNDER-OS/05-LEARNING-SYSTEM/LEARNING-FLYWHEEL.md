# Learning Flywheel

Correction or decision → written down in the right place (ADR, `AGENTS.md`, or Parking Lot) → the next AI session reads it via `AGENTS.md` before starting work → work doesn't repeat past mistakes → new corrections become rarer and more specific over time.

This only works if the second step actually happens. An unwritten correction isn't part of the flywheel — it's a hallway conversation that will need repeating.
