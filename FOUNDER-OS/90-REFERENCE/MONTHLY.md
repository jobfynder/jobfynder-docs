# Monthly — Quick Reference

**No monthly cadence existed anywhere in this repo before this file.** This is a first draft built from patterns this project has actually hit, not an extracted existing practice — adjust it to fit as you actually use it.

- **Repo audit.** This project has repeatedly found stale, empty, or duplicate repos and folders that accumulated silently for months before anyone noticed (see `Infrastructure/CHANGELOG.md` and the repo-archival history). Once a month, scan for exactly that pattern before it becomes a bigger cleanup later.
- **Parking Lot items untouched for a full month** are candidates to drop outright, not just re-park.
- **Cross-check docs against code** for anything that shipped this month — the role-count and empty-folder mismatches this project has already hit came from docs and code drifting apart silently.
